# HowToLiveBetter-Local

《[高性价比人生指南](https://github.com/eternity4719/HowToLiveBetter)》的本地镜像 + 结构化数据抽取 + 本地检索页。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `upstream/` | 上游仓库的完整快照（正文、文档、工具、技能），不含 `.git` |
| `data.json` | 从正文抽取的结构化循证建议，**650 条** |
| `index.html` | 本地检索页：搜索框 + 主题分类导航 + 卡片列表（点击展开） |
| `tools/extract_data.py` | 抽取脚本：`upstream/book/*.md` → `data.json` |
| `tools/build_index.py` | 生成脚本：`data.json` → `index.html` |
| `tools/check_layout.py` | 布局测试：在 12 档屏幕宽度下检查横向溢出 |
| `tools/check_search.py` | 功能测试：搜索、分类筛选、证据等级排序共 23 项断言 |

## 数据来源

- 上游仓库：<https://github.com/eternity4719/HowToLiveBetter>

## data.json 字段

共 650 条，按正文顺序排列。每条包含：

| 字段 | 含义 | 对应正文 |
| --- | --- | --- |
| `标题` | 条目标题 | `### N. 标题` |
| `内容` | 说人话，条目的通俗说明 | `- 说人话：` |
| `所属主题` | 所属章节主题，如「不要早死」 | 章节一级标题 |
| `成本` | 花掉什么 | `- 成本：` |
| `收益` | 换回什么 | `- 收益：` |
| `证据等级` | `A` / `B` / `C`（少数带括号说明） | `- 证据等级：` |
| `来源出处` | 期刊论文与官方文件 | `- 来源：` |
| `备注` | 附加说明（附加字段） | `- 备注：` |
| `源文件` | 来源文件路径（附加字段） | — |
| `条目编号` | `章节序号-条目序号`，如 `1-3`（附加字段） | — |

证据等级分布：A 425 · B 170 · C 50，另有 5 条带括号补充说明（如 `A（争议）`）。

## index.html 页面说明

全部用原生 JavaScript 实现，未引入任何第三方库。

### 搜索

- **匹配范围**：只匹配 `data.json` 的 `标题`、`内容`、`所属主题` 三个字段（常量 `SEARCH_FIELDS`）。
  刻意不搜 `成本 / 收益 / 备注 / 来源出处`，否则会命中卡片收起状态下看不见的文字，
  看起来像「搜出来的东西不含关键词」。
- **模糊匹配**：大小写不敏感的子串匹配；关键词按空白拆开，多个词之间是 **AND**（都命中才算）。
  例如「血压 筛查」= 两个词都出现。
- **实时响应**：`input` 事件触发，带 120ms 防抖；命中的关键词用 `<mark>` 高亮，
  且搜索时摘要的行数上限从 2 行放宽到 4 行，让命中的位置更容易露出来。
- 高亮只用 DOM 节点（`createTextNode` / `<mark>`）拼接，不经过 `innerHTML`，没有注入风险。

### 分类筛选

- 横向滚动的分类导航，目前放了「健康 / 金钱 / 职场」3 个分类；点一下筛选，**再点一下取消**，回到全部。
- 分类与章节主题的映射写在 `CATEGORIES` 常量里（`index.html` 与 `tools/build_index.py` 内各一份），
  34 个章节主题当前已全部归入这 3 类，改这一处即可调整。当前口径：健康 17 个主题 / 327 条，
  金钱 10 个主题 / 210 条，职场 7 个主题 / 113 条。
- 搜索与分类可以叠加，两者是交集关系。

### 排序

- **所有结果都按证据等级排序：A → B → C**，默认视图也一样。
- 同一等级内保持 `data.json` 的原始顺序（用「原始下标 + 等级」显式做稳定排序，
  不依赖引擎的 `Array.prototype.sort` 是否稳定）。
- 等级取值含 `A（争议）`、`B（指南强推荐，但底层证据等级低）` 这类带括号的写法，按首字母归类。
- 状态栏右侧固定标注「按证据等级 A→C 排序」。

### 卡片

- 默认展示全部 650 条；每条是卡片，点击（或聚焦后按 Enter/空格）展开 `成本 / 收益 / 备注 / 来源出处`。
- 展开内容按需渲染，首屏只渲染标题与摘要。
- **配色与适配**：浅蓝 + 白色，纯 CSS；≥780px 两列、以下单列；已测 320–1920px 无横向溢出。

### 打开方式

- **直接双击**：`file://` 下浏览器会拦截 `fetch`，页面自动回退到构建时内嵌的**全量** 650 条数据，
  搜索和筛选照常可用（页脚会标注「内嵌快照」）。
- **本地起服务**（读取外部 `data.json`）：

  ```bash
  python3 -m http.server 8000
  # 打开 http://127.0.0.1:8000/index.html
  ```

## 重新生成

```bash
python3 tools/extract_data.py    # upstream/book/*.md -> data.json
python3 tools/build_index.py     # data.json          -> index.html
```

`extract_data.py` 会自检：7 个必填字段全非空，否则以非零码退出。

## 测试

需要本机装有 Edge/Chrome。

### 布局测试

```bash
python3 tools/check_layout.py                      # 默认 320 / 360 / 375 / ... / 1920 共 12 档
python3 tools/check_layout.py --widths 320,768,1440
python3 tools/check_layout.py --browser /path/to/msedge
```

脚本把 index.html 放进一个可调宽度的 iframe 里逐档测量（无头浏览器在 Windows 上有约 496px 的
最小窗口宽度，直接用 `--window-size` 测不到 320/375 这类手机宽度）。检查项：页面横向溢出、
元素越界、视口是否按预期生效。

### 搜索与筛选功能测试

```bash
python3 tools/check_search.py
```

用真实事件驱动搜索框和分类按钮，跑 23 项断言，覆盖：默认全量与排序、单关键词命中、
命中项确实含关键词、来源/备注不再命中、多关键词 AND、清空恢复、分类筛选与取消、
状态栏选中态、搜索与分类叠加、无结果提示、复位。
